# 个人观影/阅读清单与评分分析

一个前后端分离的个人观影与阅读管理平台，支持录入、打分、短评，并提供多维度的数据分析看板。

## 功能预期

### 清单管理
- 添加/编辑/删除影视或书籍条目
- 录入信息：名称、类型（电影/剧集/书籍）、标签/分类、观看/阅读日期、评分（1-10）、短评
- 支持按名称搜索、按类型/标签/日期筛选

### 影视信息补全
- 录入时通过豆瓣或 TMDB 公开 API 自动补全影片信息（导演、年份、简介、海报）

### 数据分析看板
- 评分分布直方图 —— 直观展示高分段与低分段数量
- 按类型/导演/年份的平均分对比（柱状图）
- 观看/阅读时间线（时间轴或月历热力图）
- 类型偏好雷达图 —— 分析用户偏爱哪些类型

## 技术方案

| 层级 | 技术 |
|------|------|
| 前端 | React (Vite) + ECharts + Axios |
| 后端 | Node.js + Express |
| 数据库 | SQLite |
| 外部 API | 豆瓣 / TMDB |

## 表结构（预期）

- **items** —— 影视/书籍条目
- **tags** —— 分类标签（可与 items 多对多关联）
